## Exercise 4 – Basic Loop

- **Category:** Basic Loop

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 3, Exercise 3.32

- **Description:** Displays a formatted table containing numbers from 1 to 10 along with their squares and cubes.

- **Concepts Used:** `for` loop, tab control characters (`\\t`), loop control variable counter.

- **How it Works:** A `for` loop initializes `i` at 1 and iterates while `i \<= 10`. During each pass, it prints `i`, `i^2`, and `i^3`.

- **Example Run:**

- ```
Number  Square  Cube
```
