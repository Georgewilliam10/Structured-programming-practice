## Exercise 1 – Basic Output

- **Category:** Basic Output

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 2, Exercise 2.3

- **Description:** Displays a structured welcome banner to the console displaying course and department details.

- **Concepts Used:** `printf()`, escape sequences (`\\n`), standard header \`\`.

- **How it Works:** The `main` function executes three sequential `printf` calls. Each statement outputs a line of text to standard output, ending with a newline character.

- **Example Run:**

- ```
Welcome to C Programming!  
Course: CSC1101 - Structured Programming  
Department: Computing & Technology
```
