## Exercise 3 – Decision

- **Category:** Decision

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 2, Exercise 2.26

- **Description:** Takes two integers and evaluates whether the first is a multiple of the second using the remainder operator.

- **Concepts Used:** `if...else` statement, modulus operator (`%`), equality operator (`==`).

- **How it Works:** After accepting two integer inputs, the program checks if `num1 % num2` equals zero. If true, it outputs that the first number is a multiple; otherwise, it outputs that it is not.

- **Example Run:**

- ```
Enter two integers: 15 5  
15 is a multiple of 5
```
