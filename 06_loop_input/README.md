## Exercise 6 – Loop with User Input

- **Category:** Loop with User Input

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 4, Exercise 4.11

- **Description:** Asks the user how many floating-point values they wish to process, reads those values one by one inside a loop, and outputs the total and average.

- **Concepts Used:** Dynamic loop control using user input, accumulator (`total`), `scanf` inside loop iterations.

- **How it Works:** Prompts for the total count of values, then loops `count` times. In each iteration, `scanf` grabs a number and adds it to `total`. Finally, it computes and prints the average.

- **Example Run:**

- ```
How many numbers would you like to enter? 3  
Enter number 1: 12.5  
Enter number 2: 7.5  
Enter number 3: 20.0  
  
Total: 40.00  
Average: 13.33
```
