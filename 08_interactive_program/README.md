## Exercise 8 – Interactive Console Program

- **Category:** Interactive Console Program

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 4, Exercise 4.28

- **Description:** Simulates an interactive ATM menu allowing continuous operations (balance check, deposit, withdrawal) until the exit option is chosen.

- **Concepts Used:** Sentinel/menu-driven `while` loop, `switch` statement, input processing, conditionals.

- **How it Works:** Executes inside a `while (choice != 4)` loop. Evaluates user options through a `switch` block, modifying or outputting the current account balance according to user inputs.

- **Example Run:**

- ```
--- Simple ATM Menu ---  
1. Check Balance  
2. Deposit Funds  
3. Withdraw Funds  
4. Exit  
Enter choice (1-4): 1  
Current balance: $1000.00
```
