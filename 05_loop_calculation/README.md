## Exercise 5 – Loop with Calculation

- **Category:** Loop with Calculation

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 4, Exercise 4.10

- **Description:** Calculates and prints the total sum of all even integers from 2 through 100.

- **Concepts Used:** `for` loop, accumulator pattern (`sum += number`), step increments (`number += 2`).

- **How it Works:** The control variable starts at 2 and increments by 2 per iteration. Each step adds the current value to an accumulating `sum` variable.

- **Example Run:**

- ```
Sum of even integers from 2 to 100 is: 2550
```
