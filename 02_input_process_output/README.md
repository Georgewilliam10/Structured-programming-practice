## Exercise 2 – Input, Process, Output

- **Category:** Input – Process – Output

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 2, Exercise 2.19

- **Description:** Prompts the user to enter three integers, calculates their sum, average, and product, and prints the results.

- **Concepts Used:** Integer and floating-point variables, `scanf()`, arithmetic operators (`+`, `/`, `\*`), format specifiers (`%d`, `%.2f`).

- **How it Works:** The program allocates space for five variables, reads three user inputs using `scanf`, performs arithmetic operations, and outputs formatted results.

- **Example Run:**

- ```
Enter three integers: 10 20 30  
Sum is 60  
Average is 20.00  
Product is 6000
```
