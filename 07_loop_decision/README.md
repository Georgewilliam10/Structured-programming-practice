## Exercise 7 – Loop with Decision

- **Category:** Loop with Decision

- **Textbook Reference:** Deitel & Deitel, 9th Edition, Chapter 3, Exercise 3.22

- **Description:** Processes exam results for 10 students, tracking passes and failures, and checks if an instructor bonus condition is met.

- **Concepts Used:** `while` loop, counter variables (`passes`, `failures`), nested `if...else if` input validation.

- **How it Works:** A `while` loop runs until 10 valid student entries are processed. An internal `if...else if` structure updates pass/fail counters or requests re-entry on invalid input.

- **Example Run:**

- ```
Enter result (1 = pass, 2 = fail): 1  
Enter result (1 = pass, 2 = fail): 1  
...  
Passed: 9  
Failed: 1  
Bonus to instructor!
```
